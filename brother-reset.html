Brother Printer Reset Guide

Clear "Ink Absorber Full" / Error 46, drum counters and toner lockouts on Brother printers — using the printer's own built-in menus. No paid reset keys. Nothing to download.

Read this first. Brother's waste-ink counter exists because a real sponge inside the printer is soaking up purged ink. Resetting the counter does not empty the sponge. If it is truly saturated, ink can leak onto your desk or the printer's electronics. Before you reset, do one of these: replace the absorber pads, clean them out, or fit an external waste-ink bottle. Resetting is safest when the count is high but the pads are still mostly dry.

    If it doesn't work

    • Wrong button combo? The way you get into maintenance mode changes between model years. Search for "[your model] service manual maintenance mode". Brother's service manuals spell it out.
    • No PURGE line under code 80? Some models call it FLUSH or list several purge counters. Reset each one with the same code.
    • Error comes back right away? The printer may be detecting a real fault, such as a jammed carriage or a failing pump, rather than reading a counter. Get a repair quote.
    • Stuck in maintenance mode? Enter 99 or turn the power off and on.
